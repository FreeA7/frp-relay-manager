# Docs

Local documentation for `frp-relay-manager`.

- `SERVER_DEPLOY_EDGE_GATEWAY.md` describes the production SSH target and
  deployment guardrails.
- `LOCAL_WORKFLOW.md` describes local Git, development, and release flow.
- `CLIENT_DEV_TEST.md` describes client-agent development and local testing.
- `CLIENT_ONBOARDING.md` is the client-facing setup and connection guide.
- `SERVER_DEPLOY_KCHAT.md` and `FRP_RELAY_HANDOFF.md` are legacy kchat records;
  they are not current connection or deployment procedures.

Do not write secrets, DNSPod tokens, frps tokens, or generated passwords into
these documents.
